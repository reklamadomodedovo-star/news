# «ФОКУС» — прототип информационного портала

Демонстрационный **интерактивный прототип** новостного портала, собранный по двум техническим заданиям заказчика:

1. **«ТЗ для Дизайнера»** — дизайн информационного сайта с рекламой: спокойные цвета, крупный шрифт, много воздуха, календарь и поиск на первом экране, рубрики-плитки, афиша, статья с подзаголовками и блоком «Читайте также», реклама нейтральными блоками с тонкой рамкой (не поверх изображений, на телефоне ≤ 200 px), адаптив, UI-кит.
2. **«ТЗ инфо сайта WORDPRESS»** — структура и функции: новости, календарь событий, каталог, обзоры, полезное; роли; статистика просмотров и кликов; экспорт JSON/CSV; бэкапы; логи; интеграции Метрика/GA/вебмастера; требования по скорости, SEO, безопасности и масштабируемости.

Прототип — **один самодостаточный файл** `index.html`: 8 экранов, адаптив 1280 / 834 / 390 px, переключатели устройств и рекламной разметки, тёмная тема, живая анимация и рабочие интерактивные механики.

## Что внутри прототипа

- **8 экранов:** Главная, Статья, Календарь событий, Каталог и обзоры, Админ-панель, UI-кит, WP: реализация, Соответствие ТЗ.
- **Адаптив:** «Компьютер 1280 / Планшет 834 / Телефон 390» — реализован на container queries, проверен автотестом на отсутствие горизонтального переполнения.
- **Реклама:** 13 зон AD-1…AD-13 с форматами для ПК и телефона; тумблер «Разметка рекламы» показывает зоны, форматы и правила; нативные блоки помечены отдельно.
- **Живые механики:** бегущая строка срочных новостей, лента обновлений с новыми записями, счётчики просмотров, опрос недели, блок «Для вас» с памятью прочитанного, тёмная тема, прогресс чтения.
- **Интерактив:** фильтры календаря, выбор дня, аккордеон «Подробнее», «Напомнить», экспорт `.ics`, формы подписки и комментариев, мобильное меню, админка с тумблерами рекламных зон.
- **Редакционная фотография** во всех визуальных блоках, с подписями и авторством снимков.

## Структура репозитория

```
index.html            собранный прототип (открывается как сайт)
project.html          хаб: материалы проекта и галерея макетов
report.html           аналитический отчёт (7 разделов, SVG-графики)
brief.md              бриф проекта
HANDOFF.md            полная передача проекта (контекст, грабли, план)
build.sh              сборка index.html из партиалов
_parts/               исходники прототипа (склеиваются по порядку)
  a-head.html         <head> + CSS + экран «Главная»
  b-screens.html      экраны «Статья» и «Календарь»
  c-catalog.html      экран «Каталог и обзоры»
  d-admin.html        экран «Админ-панель»
  e-kit.html          экран «UI-кит»
  z-img.html          генерируемый: фотографии в data-URI
  g-wp.html           экран «WP: реализация»
  f-check-script.html экран «Соответствие ТЗ» + иконки + вся JS-логика
tools/add_images.py   пересборка фотографий и разметки <img>-мест
img/                  исходные фотографии
makety/               макеты: PNG для сдачи + makety/web/ лёгкие превью
_shots/               скрипты проверки (Playwright): скриншоты, автотест, темы
```

## Сборка и проверки

```bash
bash build.sh                  # собрать index.html из _parts/
python3 tools/add_images.py    # пересобрать фото в data-URI (если меняли img/)
python3 _shots/test.py         # автотест: overflow 390/834/1280, реклама, формы, JS
python3 _shots/shoot.py        # 13 скриншотов + диагностика
python3 _shots/theme.py        # тёмная тема, липкая шапка, живые механики
```

Скрипты проверки требуют Playwright:

```bash
pip install playwright
python3 -m playwright install chromium
python3 -m playwright install-deps chromium    # нужен root
```

> **Важно:** `index.html` собирается **только** через `bash build.sh`. При ручной склейке партиалов легко потерять экран — так уже случалось с `g-wp.html`.

## Аналитика, на которой основаны решения

В `report.html` — сводное исследование: топ-30 порталов мира и России по визитам (Similarweb), поведение читателя (Reuters Institute DNR 2025/2026, Pew Research, Mediascope), влияние внешнего вида на удержание и доверие, плотность рекламы, скорость загрузки (Google, BBC), практика Society for News Design. Основной вывод: дизайн не приносит трафик, но управляет удержанием, доверием и монетизацией — отсюда формула проекта «строгое издание по виду + лента и живые механики по поведению».

## Тексты и изображения

Все тексты, названия, цифры и события — **демонстрационные** (вымышленное издание «ФОКУС»). Фотографии сгенерированы для макета и используются как placeholders; в продакшене заменяются на снимки редакции через `img/` + `tools/add_images.py`.

## Лицензия и статус

Прототип подготовлен как рабочий материал проекта по заказам на Kwork. Код вёрстки и дизайн-система могут быть переданы заказчику; демонстрационные тексты и изображения — только для показа макета.
