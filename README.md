# «ФОКУС» — информационный портал (прототип)

Интерактивный прототип новостного портала по двум техническим заданиям:
- **Дизайн информационного сайта с рекламой** (спокойные цвета, крупный шрифт, много воздуха, календарь и поиск на первом экране, рубрики-плитки, афиша, статья с подзаголовками и блоком «Читайте также», нейтральная реклама, адаптив, UI-кит)
- **Сайт на WordPress** (структура и функции: новости, календарь событий, каталог, обзоры, полезное; роли; статистика просмотров и кликов; экспорт JSON/CSV; бэкапы; логи; интеграции; требования к скорости, SEO, безопасности и масштабируемости)

## Что на сайте

| Страница | Описание |
|---|---|
| [`index.html`](index.html) | **Интерактивный прототип** — 8 экранов: Главная, Статья, Календарь событий, Каталог и обзоры, Админ-панель, UI-кит, WP-реализация, Соответствие ТЗ. |
| [`report.html`](report.html) | Аналитический отчёт (исследование рынка и поведения читателя — 18 источников, Similarweb, Reuters Institute DNR, Pew Research, Mediascope, Google). |

### В прототипе

- **8 экранов** с навигацией по табам в верхней панели.
- **Адаптив** «Компьютер 1280 / Планшет 834 / Телефон 390» — переключатель устройств в шапке.
- **13 рекламных зон** AD-1…AD-13; тумблер «Разметка рекламы» показывает зоны, форматы и правила.
- **Живые механики**: бегущая строка срочных новостей, лента обновлений, счётчики просмотров, опрос недели, блок «Для вас», тёмная тема, прогресс чтения.
- **Интерактив**: фильтры календаря, выбор дня, аккордеон «Подробнее», «Напомнить», экспорт `.ics`, формы подписки и комментариев, мобильное меню, админка с тумблерами рекламных зон.

### Навигация по прототипу

Верхняя панель прототипа содержит:
- переключатель экранов (Главная, Статья, Календарь, Каталог и обзоры, Админка, UI-кит, WP: реализация, Соответствие ТЗ);
- переключатель устройства (Компьютер / Планшет / Телефон);
- тумблеры «Разметка рекламы» и «Сетка».
